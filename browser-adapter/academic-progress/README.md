# 上海大学学业进度导入扩展

这是本地开发版浏览器扩展，用于读取学生自己已登录的学业情况页面，将类别树和课程状态传回当前打开的 CoursePilot 学业资料页。扩展不读取密码或 Cookie，也不执行学校页面代码。

1. 在支持 Chromium 扩展的浏览器打开扩展管理页面，启用开发者模式，选择“加载已解压的扩展程序”，选择此目录。
2. 登录上海大学教务系统，打开“学生学业情况查询”。
3. 先在 CoursePilot 的学业资料页连接导入扩展，再回到教务页面点击右下角“导出到 CoursePilot”，核对类别和课程状态。

扩展保留类别节点 ID、父子关系和学校类别编号。同名父类别与子类别仍为两个节点。课程状态只按可读取的明确文本、`title`、`aria-label` 或图片 `alt` 标签识别；缺少可识别标签时写为 `UNKNOWN`，不会根据成绩栏推断已通过状态。发送成功仅在 CoursePilot 返回 Java 服务持久化结果后确认；没有有效连接或保存失败时扩展报告失败，可重新连接后重试。导出 JSON 仅作为手工交接选项。
