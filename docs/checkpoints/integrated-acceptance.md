## 真实模型与外部数据

配置来自本机忽略目录中的 stack.env。有效规划请求通过本地 Pydantic 校验后，共进行两次人工发起的真实模型尝试：第一次 API 返回 HTTP 422、MODEL_INVALID_OUTPUT，提示响应缺少 content；第二次同样返回 MODEL_INVALID_OUTPUT，提示模型输出不是 JSON。第二次可以确认取得了非空 content 字符串，但无法解析为 JSON。原 provider 响应结构、finish_reason 和 usage 未留存，原因未查明。没有自动重试，也未将受控模型结果计入真实模型成功次数。

错误诊断现覆盖缺少 content 和 JSON 解析失败两条分支，仅记录结构分类、受限 finish_reason、HTTP 状态和 token 用量；已知用量计入运行预算，对应模拟测试通过。真实模型推荐尚未通过验收。

正方扩展直接回传、页面图标状态对照、真实评价在模型输出中的对应关系，以及真实目标学期开课快照下的换班和课表，均未完成本次浏览器验收。文件导入通过不能替代扩展跨标签页回传验收。
