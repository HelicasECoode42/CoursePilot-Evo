# A1 交付说明：2024 级计算机学院培养计划课程清单

状态：负责人已审阅 A1 输出说明；`.xlsx` 是 A2 正式输入格式。

## 交付内容

工作簿 `2024-computer-college-curricula.xlsx`（整理自《总体及分专业课程清单.xlsx》）是 A1 的结构化整理成果，供本地 A2 导入使用。出于仓库数据规则，该真实教学计划工作簿不放在公开 GitHub 仓库；本机可将它放在被忽略的 `data/raw/` 下。它覆盖计算机学院 2024 级八条并列专业路径：

- 计算机科学与技术（直招、分流）
- 智能科学与技术（直招、分流）
- 网络空间安全（直招、分流）
- 人工智能（直招、分流）

工作簿包含总体清单和各路径清单，整理类别学分要求、课程/课程组明细、课程编号、名称、类别、学分、建议学期、原表位置及备注。课程组或毕业要求行与单门课程分开标记；选修范围不等同于每门都必须修读。

## 来源与核对说明

原始依据为学校提供的《以此为准，计算机2024级教学计划表20250306.xls》。整理结果保留原表工作表与单元格位置，方便追溯。

负责人确认已逐项核对八条路径的课程编号、名称、类别、总学分、实践学分、原表位置和学期安排。未能从主表确定的课程组或规则仍按原文保留并标记待确认；该状态不表示规则已被解释或实现为自动审核逻辑。

## 使用边界

- 这是培养计划整理数据，不是当前学期开课/班次数据，也不是学生个人学业记录。
- 建议学期用于呈现培养计划安排，不构成本学期必须开课的事实。
- 原表中没有展开的附表课程、课程组或待确认规则，不能据此生成具体课程事实或确定的规则判断。
- 本工作簿是 A1 人工整理交付，也是 A2 当前正式导入格式。Importer 按请求指定的 ASCII `trackId` 读取对应中文路径页签；它不读取原始学校 `.xls`。未知规则仍会阻断自动发布，详见 [A2 导入器说明](../java-environment/importer/README.md)。
