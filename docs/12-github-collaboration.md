# GitHub 入组与协作入口

仓库：[CoursePilot-Evo](https://github.com/HelicasECoode42/CoursePilot-Evo)，当前公开。负责人见[模块索引](05-team-and-sub-trds.md)，项目/模块理解见[团队总览](15-team-baseline-and-batches.md)。

## 入组

队长在仓库 Settings → Collaborators 按确认的 GitHub 账号邀请；接受后才有仓库权限。Project 权限与仓库权限分别管理，看板可访问不代表已经获得仓库写权限。邀请状态以实际设置为准，公开文档仅使用账号。

## 开发与复核

领业务任务、更新看板、短分支、小 PR、接口消费方复核、人工验收关单和 Bug 操作统一见[团队操作指南](18-team-progress-guide.md)。每次提交的检查与日志边界见[工程规范](16-engineering-and-debugging.md)，填写[PR 模板](../.github/pull_request_template.md)。

分支保护与强制审批是否启用以仓库设置为准。CI 校验契约/样例、基础文档与已有模块；未实现模块 SKIP 不能代表系统可用。合并前检查最终版本的适用 CI 与审批证据。

学校原始文件、成绩、密钥、私有运行/评测答案按工程规范保持受控；老师报告使用受限入口。这里不再维护另一份任务状态或复核清单。
