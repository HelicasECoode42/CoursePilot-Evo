## 项目名称

CoursePilot-Evo——基于可信规则核验与智能体自优化的学业规划系统

## 项目描述

学生制定学期选课计划时，需要同时核对培养要求、已修课程与分类学分缺口，并查阅不同教师的授课体验、给分反馈、签到要求、作业和考核方式。这些信息往往分散，学生也未必能一次说清自己的目标。本项目拟开发一个引导式学业规划网页，将相关信息集中呈现，正常使用从已关联学业记录开始，缺记录时提供导入入口。系统先核对未完成要求与建议修读，再一次问一个问题，帮助学生表达高绩点、低工作量、评价好、指定教师、兴趣、职业或时间等可组合目标。职业方向根据专业提供介绍，但不是每个学生的必填项。

系统分为确定性核验与智能规划两层。Java、Spring Boot 和 MySQL 导入2024级计算机类教学计划，自动校验已知格式、保存来源与版本，计算学分、核对培养要求并验证计划硬条件；无法可靠解析的数据会被拦截并标记为未知。Python 规划智能体识别学生的硬条件、兴趣与可协商偏好，按需调用 Java 工具，提出课程方案并解释取舍。页面把已核验事实、建议、主观评价和未知信息分开展示。少量经授权或虚构的教师评价摘要可用于演示参考，但历史评价不能证明该教师本学期授课或课程“容易拿高分”。

项目还将设计培养要求核对、偏好理解、重规划和信息缺失时澄清等任务组，记录执行过程、正确率、规则违规、工具调用、Token 和耗时。对于多个任务中重复出现的失败，尝试由 Evolver 修改可版本化的技能或工具/上下文策略，再经隔离测试决定晋级或回滚，以验证 Harness 自进化是否改善质量和效率。五人计划在五周内分别负责数据、Java 核验、规划 Agent、评测/演化、网页/集成。当前尚不能实测真实教学班，时间冲突先用标明为模拟的数据验证；没有真实快照时只做课程层面的规划，不编造真实课表。系统不代替学生在学校系统实际选课。
