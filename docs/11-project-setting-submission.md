# 项目设定提交版

> 2026-09-29｜五人团队、五周开发。可复制下面三项到课程系统，PDF 附件可直接上传。当前为方案与数据核查阶段，尚未实现可运行系统。

## 项目名称

**CoursePilot-Evo：基于可信规则核验与智能体自优化的学业规划系统**

## 项目描述

面向学生培养要求核对和选课规划，拟开发一个可追溯的 Web 系统。以 2024 级计算机类教学计划为数据依据，由 Java/Spring Boot 与 MySQL 导入课程和培养规则，自动校验数据、计算学分与要求、验证计划约束；由 Python Planning Agent 理解学生目标、调用 Java 工具并解释结果。系统用任务组 Benchmark、执行 Trace 和隔离的留出测试，研究如何把反复有效的规划经验沉淀为可复用 Skill/工具调用策略，并比较正确率、Token 和耗时。五人分工、五周开发；首版展示层为网页，仅辅助规划，不执行选课。当前真实教学班数据尚不能实测，时间冲突功能先用明确标记的模拟数据验证，真实开课信息不足时提示未知。

## 项目状态

**可行性研究**。已有本地独立项目目录、原始教学计划和插件源码核查、总体与分工设计；尚未有可运行的 CoursePilot Java/Python/Web 系统或真实选课页接入。老师审核通过后按五周安排进入实现。
