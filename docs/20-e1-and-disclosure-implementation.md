# E1 引导页面与仓库自查修复方案

对应 Issue #4（学生表达目标）和 #1（已跟踪私有文件漏检）。基于已讨论的团队业务文档实施，不扩大到 Java 规则服务、课程详情或推荐结果实现。

## 学生实际使用的流程

学生选择多个目标 → 只回答相关问题 → 明确必须条件和偏好 → 主动确认目标优先级 → 检查已填写内容 → 交给后续推荐流程。返回上一步保留内存答案；更改目标后，不再提交被取消分支的答案。没有学业资料时，明确提示需要补充，不能制造学业记录 ID。

Vue Router 管理当前问题；会话状态持有填写内容和请求状态；唯一 API 入口负责 Python HTTP、封套、认证、超时和错误。业务分支和请求映射可独立测试，但不拆只转发参数的无意义函数。仅当前问题挂载，键盘和窄屏可操作。

真实模式调用已有会话契约；演示模式显著标识，使用虚构共享样例，不静默兜底为成功。会话 bearer 仅内存保存，不进 URL、持久化存储或日志。刷新创建新会话，不承诺恢复旧记录。请求失效、失败、重复点击和迟到响应需有明确处理。E1 提供有效 PlanningRequest 的交接能力；没有实际后端时不得称联调完成。

## 自查检查怎样修复

默认扫描 Git 跟踪清单，路径门禁先于内容读取，覆盖 data/raw、data/private 等禁止路径。本地忽略且未跟踪的授权输入不当作提交。staged 模式读取暂存区内容；暂存删除不误报，工作区内容不替代暂存区。错误仅显示必要路径和原因，不输出敏感内容。

独立临时 Git 仓库覆盖：强制跟踪私有路径、普通文本、忽略未跟踪输入、暂存内容与工作区不同、暂存删除。回归测试接入 CI。

## 第一版实际验证（37 项前端测试）

本次变更在 `feat/guided-planning-and-disclosure-check` 分支。前端工程检查包括 lint、类型检查、37 项单元测试和生产构建；仓库契约检查与 5 项独立临时 Git 仓库自查回归均通过。另用临时 Git 索引检查全部拟提交的新文件和修改，不改变开发者实际暂存区，避免只检查已跟踪旧文件而漏掉新模块。

浏览器实际检查了真实服务不可连接时的错误／重试提示，以及显式演示模式的多目标选择、返回保留、未选职业目标时跳过该分支、选择职业目标后的补充问题、键盘 Space／Enter 操作和最终请求检查。390 × 844 窄屏页面无横向溢出；最终检查页可核对优先顺序、必须避开的星期和节次。刷新会回到新会话入口。测试均使用虚构内容，没有调用真实推荐服务。

独立审核要求修复最终答案摘要缺失、取消时间目标后的模式残留和会话过期未及时失效，并补充真实资料来源限制与上海时区日期显示。到期清除身份与资料并保留本页答案，刷新则全部重新开始。过期和迟到响应使用单元测试验证；浏览器测试不替代真实后端联调，也不代表完整应用已经可用。

独立 Luna xhigh 最终复核通过：上述问题与重复编号已修复；来源类型为 `SYNTHETIC` 时，即使校验状态误标 `VERIFIED` 也会被真实模式拒绝。审核者重新运行 37 项前端测试、lint、类型检查、生产构建及 diff 检查，未发现剩余必须修复问题。此结论仅覆盖本次变更。

## 按 HTML 演示补齐学生理解入口

上一轮验证针对第一版，不表示 HTML 演示中的所有业务已实现。本轮按学生实际决策补齐上课与考核偏好：给分反馈、考勤、作业、小组任务、汇报与考核形式分别表达，不用单一“轻松”选项替代。只有相关目标触发该页，允许全部不选；撤销全部相关目标后清除该分支答案。

时间改为两个独立问题：“哪些时间必须空出来？”和“哪些时间尽量空出来？”。两组答案可以同时存在，分别进入硬条件和软偏好；每页不选就表示该类没有要求，不先问用户条件属于哪类。返回保留各组答案，取消时间目标清空两组。星期表示整天，节次表示每天对应节次，界面明确这一含义；当时的 `BLOCK_DAY`、`BLOCK_SECTION` 契约不能把周一和第 1 节误解释为仅周一第 1 节。**此段为当时记录，已被后续决定取代**：契约已增加 `BLOCK_SLOT`，时间页改为课表网格，见[最新交互调整](#最新交互调整课表网格与必修优先)。

页面沿用 HTML 的白绿、留白与单问结构，按 [Web 视觉与交互规范](22-web-visual-spec.md) 校对文字层级、可选状态和实际交互。最终页分别核对上课偏好、必须避开的时间、尽量避开的时间和目标优先顺序。教师课程与真实推荐继续遵从对应模块职责，等待实际接口和资料，不复制 HTML 的固定虚构候选充当功能。

本轮验证：44 项前端测试、lint、类型检查、生产构建、契约和自查回归通过。实际浏览器验证“少作业／避开闭卷”多选、周一整天必须空出与周二整天／每天第 1 节尽量避开同时保存、两页返回独立回填、最终摘要与演示请求检查。撤销时间和课业目标后重新选择，两类时间及考核偏好均清空；全部不选可直接继续。Space／Enter 可操作，390 × 844 窄屏无横向溢出。均为显式虚构演示验证，真实推荐和服务端偏好消费效果未联调。

## 最新交互调整：课表网格与必修优先

队长决定（相邻模块尚未开工，直接改契约而不走 Issue 流程）：时间条件从「星期与节次互相独立」改为支持具体时段。

契约变更（`contracts/schemas/domain.schema.json`）：`Constraint.kind` 增加 `BLOCK_SLOT`，语义是星期与节次的交集。同时为三个时间 kind 增加条件规则，非法组合在 Schema 层就被拒绝，不再只靠文档约定：`BLOCK_DAY` 的 `section` 必须为 null，`BLOCK_SECTION` 的 `dayOfWeek` 必须为 null，`BLOCK_SLOT` 两者都必须非空。软偏好侧增加 `schedule.blocked_slot`，`value` 形如 `"3-2"`。新增正例 `planning-request-block-slot.json` 与反例 `invalid-block-day-with-section.json`、`invalid-block-slot-missing-section.json`，契约检查从 8 例增至 11 例。

保持 `schemaVersion` 为 `1.0`：A/B/C/D 均未开始实现，没有任何已发布消费者需要兼容，升版本只会让 11 个定义和四个模块一起改动而无收益。此决定记录在此与 `contracts/README.md`；若已有模块开始消费后再改契约，必须按规范升版本。

界面变更：时间页改为课表网格，横轴星期、纵轴节次，点格子表达具体时段；「必须避开 / 尽量避开」作为涂选强度切换，两组同时保留。整行整列提供快捷选择，分别归一为 `BLOCK_SECTION` 与 `BLOCK_DAY`。改成切换的原因是一页内平铺两组清单过长。

必修优先：学生的必须避开不凌驾培养要求。必修课唯一班次落在必须避开时段时，核验为 INVALID 并指出冲突的必修与时段，由学生决定放宽时段还是推迟必修；不静默忽略约束，也不为满足时间要求删除必修建议。该规则同时写入[共享契约](04-infrastructure-workflow.md)。

本轮同时修复独立 HTML 原型两处缺陷：`.timeOptions` 缺 `display:grid` 导致时间选项竖排成 20 行（页高 1954px → 1250px，桌面三列、窄屏两列）；资料核对页对未被询问的兴趣与职业方向显示「未填写」，与同页「课程与教师」的处理不一致，现统一区分「未选择此目标」与「这一项留空了」。

尚未完成：网格 UI 本身、Vue 与 HTML 的请求构造改造、相应回归测试。相邻模块开工前需知悉本次契约变更。

## 最新交互调整：取消条件分支

队长决定：取消按动机跳问。**每个学生都看到全部九步问题**（目标 → 上课与考核偏好 → 发展方向 → 兴趣主题 → 课程和教师 → 时间安排 → 确认目标顺序 → 核对学业资料 → 演示候选），每题都可留空跳过。动机不再决定问哪些题，只表达学生在意什么和优先顺序。

连带变更：改动机不再清空任何已填答案。原先取消某动机会清掉该分支的回答，在「题目永远会问」的前提下这会让学生无故丢失内容。请求构造也不再按当前动机过滤已填字段。

资料核对页因此不再出现「未选择此目标」「未填写」「暂未填写」三种措辞，统一为「这一项留空了」与「尚未选择具体课程与教师」。

时间摘要同时改为区间合并：整列仍显示「周一（整天）」，整行显示「每天第1节」，其余按「节次集合相同的星期」分组并压成区间，例如十个格子显示为「周一至周五 第1–2节」而不是逐格罗列。

本轮同步的文档：`AGENTS.md`（无关职业题跳过）、`docs/02-prd.md`（职业分支条件与 P0 验收）、`docs/trd/e-web-integration.md`（E-01、E-03、动机过滤、上课与考核偏好触发条件）。

**GitHub Issue #4 的第一条验收条件「非职业目标跳过职业题」已随本决定失效，需要改写后再验收。** 本次未修改 GitHub 上的 Issue 内容。

验证：21 项 HTML 测试（原 17 项中 3 项按新行为改写、新增 4 项）、48 项 Vue 测试、`check_html.py`、契约检查全部通过。浏览器实测只选一个目标仍走完九步，摘要显示「这一项留空了」，时间摘要显示「周一至周五 第1–2节」「周六、周日 第5节」。

Vue 侧随后完成同步：固定九步路由、课表网格、`BLOCK_SLOT` 归一化与配额防护、摘要区间合并，步骤顺序与 HTML 一致。HTML 原型自此冻结为设计存档，新增交互只在 Vue 实现。
