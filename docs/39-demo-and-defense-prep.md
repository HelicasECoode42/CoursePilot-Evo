## 三、演示路线（现场用负责人电脑）

1. 首页 → 开始规划 → 学业资料：用插件从教务导入，屏幕上显示"已保存 127 条课程记录和 45 个学校分类"。
2. 我的学业：一行显示还差多少学分，下面是各类别小表（学科基础 34、实践 30、专业选修 17……）。
3. AI 问答：问"我对人工智能感兴趣，下学期怎么选？"，点"加入待选"。
4. 逐步引导：设置"周五不排课"，其余跳过。
5. 学分选课：展示缺口落到具体小类、在读课程不会出现在候选里、每门课本学期开了几个班。
6. 生成方案（约 15 秒）：结果页左边是课表，右边是课程。切换前八周、后八周。
7. 换一个班、搜"数据库"加一门课，自动重新核验。
8. 保存到本机浏览器，或打印。

**备用**：今晚录一段 3～5 分钟的视频。现场遇到网络或模型超时，立刻切到视频。
**避坑**：全程别刷新页面（会话 30 分钟过期）；演示前先导入一次，预热服务；挑能对上老师评价的课来讲（软件工程、线性代数）。

## 四、可能被问的问题（先备好答案，负责人再补）

| 问题 | 回答要点 |
|---|---|
| AI 会不会胡编课程？ | 模型只能从 Java 给出的候选课程里选，输出要过格式校验，候选外的课程直接丢弃；学分和冲突由 Java 计算，不由 AI 判断 |
| 课表是真的吗？ | 来自学校公布的 2026-2027 秋季课表 PDF，转换后人工抽查核验，并记录核验人和抽样结果 |
| 下学期课表还没出，怎么规划？ | 暂用本学期课表做参考，页面上明确标注；下学期课表发布后重新导入即可 |
| 为什么要 Java 和 Python 两个后端？ | Java 负责确定性的事实与规则（可复核）；Python 负责模型调用和编排；职责分开，AI 改不了学分结论 |
| 学生数据安全吗？ | 不存学校密码；按会话隔离；服务只监听本机，通过隧道对外；日志不记成绩和提示词 |
| 准确率怎么评估？ | 现有评测只覆盖冒烟测试和遥测；回答质量的评测还没完成，如实说明 |
| 一次规划花多少钱 / 多久？ | 一次约 15 秒；有单会话额度和全站日上限 |
