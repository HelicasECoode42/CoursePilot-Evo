# 发给队友的 HTML 交接规范

请把本文件与 [coursepilot-guided-demo.html](coursepilot-guided-demo.html) 一起发给队友。HTML 无外部依赖，可直接用浏览器打开；它展示交互方向，不是生产前端或可工作的 Agent。团队总安排见 [开发批次](../docs/15-team-baseline-and-batches.md)。

## 交互已经确认的方向

白底、少量绿色、清晰文字、留白；一次只出现一个问题，回答后替换当前页。顶部保留产品名和学业记录入口，底部保留返回/下一步。不把所有问题、项目介绍、可信度说明和开发报告堆到一条长页面。

第一问是“本学期最在意什么”，多选：高绩点、轻松些、好评课程、指定教师课程、兴趣、职业、升学、时间。不同动机触发对应追问，未选择职业准备不问岗位。返回保留答案，不能重置已选教师和时间条件。

学业基础正常从已导入记录读取；“我的学业记录”查看/纠错，缺资料才导入。未完成必修、建议修读和类别缺口由后端计算；教学计划建议学期不是当期必须修读。

课程与教师必须一起选；“优先考虑”与“必须保留”分开。点击评价打开详情，关闭后回到当前问题。结果比较具体课程教师，来源未确认时不把意愿写成已选定当期开课班次。

## 原型有哪些占位

当前学业记录为空占位；所有课程/教师/评价为虚构示例；没有数据库、成绩导入、模型、Java 解析器和真实班次。其他专业的方向仅演示按学科切换，首版培养核对仍只做一个计算机路径。

示例候选目前是固定内容，不根据你的选择完成真实推荐。真实接入时由 PlanningAnswer 填充，不在浏览器写业务推荐规则。不要把“示例教师甲”的内容当真实种子发布。

当前粗粒度时间选项只演示 hard/soft；正式版要允许星期、节次、周次，不必一次展示全部复杂控件。Java 返回 UNKNOWN、未解析或学期/快照不一致时，页面只能说待确认；不能由前端或 Agent 宣布无冲突。

## E 如何做成 Vue

建议组件：QuestionFrame、GoalQuestion、ConditionalQuestion、AcademicRecordPanel、TeacherCoursePicker、ReviewDetail、TimePreferencePicker、CandidateList；Vue Router 管问题/结果页，Pinia 或等价会话状态保留答案。路由生成依据已确认目标及澄清状态；不能为了照抄 HTML 固定让每个人走完全部问题。

API 与字段用 [共享契约](../docs/04-infrastructure-workflow.md)。前端汇总同一 PlanningRequest，消费 AuditResult 与 PlanningAnswer；来源、学分、时间合法性与演化评分由对应后端提供。单文件 JS 只作行为示例。

学生页面使用学生能懂的词，例如“时间待确认”“这门课有往年评价”。Java、System 1/2、Trace、Harness、Benchmark、模型版本和 Token 报告放独立老师/开发者页面。

## 评审时检查

1. 打开时只看到一个问题；小屏当前问题可自然滚动，没有后续题接在下面。
2. 多动机、跳过职业、按专业方向介绍、返回保留答案都能使用。
3. 指定教师可查看评价、改变必须/偏好；不可静默换教师。
4. 评价显示课程/教师/修读学期/来源/未知；没有数据不出现假分数。
5. 学业记录正常载入，无数据有导入入口；不要求每次重写全部课程。
6. 无可靠时间来源时不出现“真实课表无冲突”。
7. 键盘能操作，焦点可见，详情关闭可返回，小屏内容不溢出。
